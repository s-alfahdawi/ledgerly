PWA icons for "Add to Home Screen" / Install prompt

Chrome and other browsers require 192x192 and 512x512 PNG icons to show the install prompt.

Add these two files in this folder:
  - icon-192.png   (192 x 192 pixels)
  - icon-512.png   (512 x 512 pixels)

Generate them from your logo at:
  https://www.pwabuilder.com/imageGenerator
  or
  https://realfavicongenerator.net/

Then redeploy and clear site data on your phone before testing again.
